# Miryoku for Cutiepie

This keymap maps Miryoku's 3x5+3 layout to the Cutiepie. The three thumb keys on each side use the six inner bottom-row positions; the two outermost bottom-row positions are disabled.

Build with:

```sh
qmk compile -kb cutiepie -km manna-harbour_miryoku
```

The keyboard definition is based on the firmware published in [flamwenco/cutiepie](https://github.com/flamwenco/cutiepie).
